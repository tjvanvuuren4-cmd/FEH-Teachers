# TJ English Coaching Lead Funnel Site

## Included
- Landing page for the free PDF guide
- Email capture form using FormSubmit
- PDF guide included in /public
- WhatsApp close path
- Coaching program section
- Teacher photo included

## Run locally
npm install
npm run dev

## Build
npm run build

## Deploy on Vercel
- Push this folder to GitHub
- Import repo into Vercel
- Framework preset: Vite
- Build command: npm run build
- Output directory: dist

## Important
This site uses FormSubmit for simple email capture:
https://formsubmit.co/

You may need to confirm the first submission sent to:
tjvanvuuren4@gmail.com

After that, captured leads will arrive in your inbox.
